# ⛏️ XMRig Mobile Kit — عدة تعدين Monero المحمولة

مجموعة أدوات مفتوحة المصدر لتعدين Monero (XMR) بواسطة XMRig على:
- 📱 هاتف أندرويد (عبر Termux) مع أيقونات Boost/Eco على الشاشة
- 💻 الحاسوب (ويندوز/لينكس/ماك)
- 🖥️ لوحة تحكم HTML عربية لمراقبة المنجم مباشرة

> ⚠️ **تنبيه قانوني:** لا تشغّل التعدين على خوادم GitHub (Codespaces/Actions) —
> هذا يخالف Acceptable Use Policy ويؤدي لحظر حسابك. شغّل على أجهزتك فقط.

## 📂 محتويات المستودع

```
xmrig-mobile-kit/
├── termux/            # أدوات هاتف أندرويد
│   ├── 1-termux-setup.sh   # بناء XMRig (يتم لصقه في Termux)
│   ├── 2-config.json       # إعدادات التعدين
│   ├── 3-start.sh          # ⛏️ أيقونة التشغيل
│   ├── 4-boost.sh          # 🔥 أيقونة رفع الهاش (100%)
│   ├── 5-eco.sh            # 🌿 أيقونة التوفير (50%)
│   └── 6-stop.sh           # ⏹️ أيقونة الإيقاف
└── dashboard/         # لوحة تحكم HTML
    ├── xmrig-dashboard.html
    └── serve.py            # خادم + جسر API
```

## 🚀 البدء السريع — الهاتف (أندرويد)

1. ثبّت [Termux](https://f-droid.org/en/packages/com.termux/) و[Termux:Widget](https://f-droid.org/en/packages/com.termux.widget/) من F-Droid
2. الصق محتوى `termux/1-termux-setup.sh` في Termux (يبني XMRig ~15 دقيقة)
3. `cp termux/2-config.json ~/config.json` ثم ضع عنوان محفظتك في `user`
4. انسخ السكربتات إلى `~/.shortcuts/` وفعّلها `chmod +x`
5. أضف أيقونات Termux:Widget لشاشتك الرئيسية

## 🚀 البدء السريع — لوحة التحكم

```bash
# في config.json الخاص بـ XMRig:
"http": { "enabled": true, "host": "127.0.0.1", "port": 10000 }

python3 dashboard/serve.py
# افتح http://127.0.0.1:8080
```
